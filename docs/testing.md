# Проверка backend

## Unit-тесты

```text
mvn test
```

Проверяются BCrypt, ограничения паролей, даты и расчёт штрафа, настройки,
нормализация логина и экранирование символов поиска.

## Интеграционные тесты

Запустите Docker с Linux-контейнерами и выполните:

```text
mvn verify
```

Тесты запускают PostgreSQL 17 в отдельном контейнере. При недоступном Docker
проверка завершается ошибкой, а не считается успешно пропущенной.

Для отдельного уже запущенного тестового PostgreSQL можно задать
`LIBRARY_TEST_DB_URL`, `LIBRARY_TEST_DB_USER`, `LIBRARY_TEST_DB_PASSWORD`.
Этот режим не использует Docker. Учётной записи нужно право создавать схемы.
Каждый запуск создаёт и удаляет только собственную схему `library_test_<uuid>`;
рабочая схема приложения не используется. Тесты не следует запускать на рабочем сервере.

Проверяются 14 таблиц, повторное применение справочников, авторизация и роли,
смена паролей, отключение пользователей, защита последнего администратора,
SQL-инъекции, работа каталога, ограничения билетов, выдача, возврат,
доступность экземпляров, история, просрочка, штрафы и смена настроек.

Отдельные проверки выполняют два конкурентных запроса выдачи на один экземпляр,
проверяют уникальный индекс напрямую и откат транзакций при ошибках сохранения
книги, билета и возврата. Все пароли тестовых пользователей создаются во время тестов.

Отчёты находятся в `backend/target/surefire-reports` и
`backend/target/failsafe-reports`; они не добавляются в Git.
